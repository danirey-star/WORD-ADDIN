# Glosario Doblaje - Office Add-in

Complemento de Word para gestión de glosario de pronunciaciones y asignación de actores.

## Instalación para Usuarios

1. Recibe el archivo `manifest.xml`
2. Abre Word
3. Ve a: **Insertar** → **Complementos** → **Mis complementos**
4. Haz clic en: **"Agregar desde archivo"**
5. Selecciona el archivo `manifest.xml`

¡Listo! El complemento está instalado.

## Uso

- Ve a la pestaña **Inicio** en Word
- Busca el botón **"Abrir panel"** en el grupo **"Glosario Doblaje"**
- O ve a: **Insertar** → **Complementos** → **Mis complementos** → **Glosario Doblaje**

## Funciones

- **Revisar documento con glosario**: Reemplaza automáticamente palabras
- **Añadir palabra al glosario**: Agrega nuevas palabras con pronunciación
- **Asignar actor a personaje**: Asigna actores a personajes en tablas
- **Importar glosario**: Carga glosario desde archivo .txt o .json

## Requisitos

- Microsoft Word (Microsoft 365)
- Windows, Mac o Word Web
